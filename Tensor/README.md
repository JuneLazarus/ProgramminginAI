## 实现过程

在实现Tensor类时，我先创建了Storage类用以存储当前张量的设备信息和元素数值
之后创建Tensor类，其中包含storage子类，当前张量形状和元素总数
接下来在tensor类中加入了大量辅助函数，方便用以检查tensor的存储内容和创建全0/全1张量（参考numpy中的zeroslike）等
.cpu()与.gpu()直接应用上课时提到的cudaMenmcpy方法
relu与sigmoid参考上课的relu_gpu代码并加以修改，加入了设备判定将两个函数合并
在所有函数的实现中均加入了较为严格的设备判定、越界检查和报错捕获输出，方便后续测试中的检查与修改

在整个过程中经历了许多波折，一开始我想的是直接在pytorch的源文件中找到tensor类的架构，但遗憾于文件过多精确查找失败，遂直接善用搜索了解到pytorch中的tensor由Storage（数据层）、TensorImpl（元数据层）和Tensor（接口层）三层组成（不一定正确），于是采用storage与etnsor双层结构实现

第一版代码百余行，简单实现了作业要求中提到的内容，还未着手于激活函数的实现，然而运行结果不尽如人意，在这一版的运行中，我获得了大量的报错，包括语法错误数据泄露与设备不匹配，报错行数甚至已经接近代码行数

经过一些努力，我成功做出了第二版，之后是第三版，……（在这里感谢几位同学的帮助和ai工具的方向指引），我终于得到了能够运行的tensor类
我原本以为激活函数的实现会顺利些，毕竟上课已经讲过了一遍。然而在实现gpu上relu时程序报错不断，实在令人汗颜，所幸经过数小时的debug我还是得到了能够运行的程序，之后的sigmoid只要完全照搬即可，但代价是现在满屏都是throw error和printf，并且多了一大堆非要求的函数。
